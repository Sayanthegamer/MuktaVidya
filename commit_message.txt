🎨 Palette: Accessibility & Micro-UX improvements

💡 What:
1. Added `aria-live="assertive"` to `ErrorBanner.tsx`.
2. Added `aria-label` to the main text area in `FloatingDock.tsx`.
3. Added `focus-within` visual indication to the `FloatingDock` input container to improve visual feedback when navigating or typing inside it.
4. Added `aria-label` to the icon-only "Rescan" button in `ChatMessageItem.tsx`.

🎯 Why:
To ensure dynamic error states are properly announced by screen readers, and that interactive input elements without visible labels are fully accessible to screen reader users. The `focus-within` on the FloatingDock creates a more polished interactive experience when using keyboard navigation.

♿ Accessibility:
- Immediate screen reader announcement on error banners.
- Clearer labels for floating dock input.
- Clearer labels for icon-only action buttons.
