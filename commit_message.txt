⚡ Bolt: [performance improvement]

💡 What: Extracted message rendering logic in `SolutionPanel.tsx` into a memoized `ChatMessageItem.tsx` component.
🎯 Why: Prevents unnecessary heavy re-renders (involving ReactMarkdown, remarkMath, rehypeKatex) for all previous completed messages on every chunk while a new message is streaming.
📊 Impact: Drastically reduces main thread CPU usage and eliminates UI stutter during model text generation by only rendering the active streaming message chunk.
🔬 Measurement: Verify by typing a message, then monitoring React DevTools or Chrome Performance profiler during generation—only the new message will re-render instead of the entire chat history.
