🎨 Palette: Add Escape key support to crop dialog

💡 What: Implemented a global Escape key listener in `components/UploadZone.tsx` to allow closing the crop image dialog using the keyboard, and added an explicit `title` with the shortcut to the Cancel button.
🎯 Why: Enhances UX and accessibility by providing an expected and commonly used keyboard shortcut to dismiss modal-like dialogs.
📸 Before/After: The dialog now closes upon pressing `Escape`, and the Cancel button tooltip indicates `Cancel (Esc)`.
♿ Accessibility: Supports keyboard navigation and improves discoverability for screen reader users and power users.
